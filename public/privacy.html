API-Ground

개인정보 처리방침

시행일: 2026년 11월 4일

API-Ground(이하 "서비스")는 웹사이트(api-ground.pages.dev), Windows 앱, Android 앱에서 다음과 같이 개인정보를 처리합니다. 로그인하지 않고도 서비스를 쓸 수 있으며, 이 경우 대화와 설정은 사용자의 기기에만 저장됩니다.

1. 수집하는 정보

항목언제용도
이메일 주소, 이름회원가입·로그인 시계정 식별, 가입 환영 메일·로그인 인증 코드 발송
Google 계정 식별자, 프로필 사진Google로 로그인 시Google 로그인 연결, 프로필 표시
비밀번호(암호화된 값만 저장)이메일로 가입 시로그인 확인
대화·프로젝트·설정로그인 후 동기화를 켠 경우여러 기기에서 같은 내용을 보기 위한 동기화
공유한 대화 내용공유 링크를 만든 경우링크를 받은 사람에게 보여주기
로그인 기록(세션), 다운로드 기록로그인·앱 다운로드 시로그인 유지, 부정 사용 방지

저장하지 않는 정보: 사용자가 입력한 AI API 키는 사용자의 기기에만 저장됩니다. 대화를 보낼 때 API 키와 메시지는 선택한 AI 회사(Anthropic, OpenAI, Google 등)로 전달만 되며, 서비스 서버에 저장되지 않습니다. 이미지·PDF 첨부와 Code 모드 세션은 동기화하지 않습니다.

2. 정보를 처리하는 곳 (위탁·제3자)

  • Cloudflare — 웹사이트 호스팅과 데이터베이스(계정·동기화 데이터 저장)
  • Google — Google 로그인, Gmail을 통한 메일 발송
  • 사용자가 선택한 AI 회사 — 대화 요청 처리. 각 회사의 개인정보 처리방침이 적용됩니다.

위 경우 외에는 개인정보를 판매하거나 다른 곳에 제공하지 않으며, 광고나 추적 도구를 쓰지 않습니다.

3. 보관 기간과 삭제

개인정보는 계정을 삭제할 때까지 보관하며, 계정을 삭제하면 계정 정보, 동기화 데이터, 공유 링크, 로그인 기록이 즉시 삭제됩니다.

계정 삭제 방법: 앱이나 웹사이트에서 설정 → 계정 → 계정 삭제를 누르세요. 앱에 접근할 수 없다면 가입한 이메일로 아래 연락처에 삭제를 요청하시면 7일 안에 처리합니다.

4. 이용자의 권리

언제든지 자신의 정보를 확인·수정·삭제하거나 처리 중단을 요청할 수 있습니다. 로그아웃하고 로그인 없이 사용하면 서버로 동기화되지 않습니다.

5. 아동

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 알고 수집하지 않습니다.

6. 보안

모든 통신은 HTTPS로 암호화되며, 비밀번호와 로그인 토큰은 복원할 수 없는 형태(해시)로만 저장합니다.

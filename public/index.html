자주 묻는 질문

무료인가요?

API-Ground 자체는 무료입니다. 각 AI 공급자의 API 요금은 해당 공급자에 직접 지불하며, NVIDIA NIM처럼 무료 체험을 제공하는 곳도 있습니다.

API 키는 안전한가요?

키는 브라우저나 앱 데이터에만 저장되고, 동기화 대상에서도 제외됩니다. 요청할 때만 해당 AI 공급자로 전달됩니다.

로그인해야 하나요?

아니요. 로그인 없이도 모든 기능을 쓸 수 있습니다. 로그인하면 여러 기기 간 동기화와 공유 링크를 사용할 수 있습니다.

어떤 모델을 쓸 수 있나요?

Claude, OpenAI, Gemini, Grok, DeepSeek, Kimi, GLM, Qwen, Mistral, MiniMax, NVIDIA NIM, Groq, OpenRouter, Together, Fireworks, Cerebras, SambaNova, Hugging Face, Cohere, Perplexity를 지원하며, 키를 입력하면 최신 모델 목록을 자동으로 불러옵니다.

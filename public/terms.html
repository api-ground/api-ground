API-Ground

서비스 이용약관

시행일: 2026년 11월 4일

1. 서비스

API-Ground는 사용자가 직접 발급한 AI API 키로 여러 AI 모델(Claude, GPT, Gemini 등)과 대화할 수 있게 해 주는 도구입니다. 서비스는 각 AI 회사와 제휴하거나 그 회사가 운영하는 것이 아닙니다.

2. API 키와 요금

AI 사용 요금은 사용자가 API 키를 발급받은 회사에 직접 청구됩니다. API 키 관리와 사용량에 대한 책임은 사용자에게 있습니다.

3. 이용자의 의무

  • 법령이나 각 AI 회사의 이용 정책을 어기는 용도로 쓰지 않습니다.
  • 다른 사람의 계정이나 API 키를 허락 없이 쓰지 않습니다.
  • 서비스를 방해하거나 무단으로 접근하려 하지 않습니다.

4. 콘텐츠

사용자가 입력한 내용과 AI가 만든 결과물의 권리와 책임은 사용자에게 있습니다. AI의 답변은 틀릴 수 있으니 중요한 판단에는 직접 확인하세요.

5. 계정 해지

사용자는 언제든 설정 → 계정에서 계정을 삭제할 수 있습니다. 약관을 크게 위반한 계정은 이용이 제한될 수 있습니다.

6. 책임의 한계

서비스는 있는 그대로 제공되며, AI 회사의 장애나 정책 변경, 사용자 기기 문제로 생긴 손해에 대해서는 법이 허용하는 범위에서 책임을 지지 않습니다.
